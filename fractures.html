How the searches work

Tiers. Tier values come from the game files (RePoE) for top-tier bases of each slot and defence type. A tier filter is the lowest value that tier can roll on any base in the search, so "T1" never lets a T2 through on that slot. If you pick a base, only its defence type is used.

Suffixes. "Only 1" means the chosen suffix is the only suffix on the item, so the 1-mod lock protects exactly that mod. "Up to 2" and "up to 3" also show items with other suffixes; you then need the 2-mod lock or the full lock (or check in game which mod the 1-mod lock keeps).

Fractured mods. The selected fractured prefixes are combined in one search ("at least one of"). A flat hybrid such as "+# to Armour and +# to Evasion Rating" shares its stats with plain flat Armour and Evasion, so a single-stat filter would also match a low tier of those. When that happens the hybrid gets its own search that requires both stats.

Filters on every search. Rare, fractured, not corrupted, not mirrored, no crafted mods, sorted by price. Searches open on the official trade site, so they use your own rate limit and nothing is stored here.

Limits. The trade site adds up every line with the same stat, so an item with two fractured mods that share a stat can pass a T1 filter with two lower tiers. Prices are asking prices: check the item before you buy.
